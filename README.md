# Template Repository for Python Packages [Minified]

A template repository for modern python package development based on
[michabirklbauer/python-pkg_template](https://github.com/michabirklbauer/python-pkg_template/).

**This is a minified and cleaned version without example code.**

Otherwise behaves the same as the original template, read [this](https://github.com/michabirklbauer/python-pkg_template/)
for further information.
